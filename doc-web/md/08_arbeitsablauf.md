# 8. Typischer Arbeitsablauf

Der empfohlene Arbeitsablauf bei der Erstbenutzung ist:

1. **Daten importieren**: Idealerweise über Click-TT (siehe [3.2 Import aus Click-TT](03_datenimport.md#32-import-aus-click-tt)).
2. **Daten überprüfen und ergänzen** über die Seite **Manuelle Eingabe** (siehe [4. Manuelle Eingabe](04_manuelle_eingabe.md)):
   1. Rastergrößen für Gruppen anpassen (siehe [4. Manuelle Eingabe: Gruppentabelle](04_manuelle_eingabe.md#linke-spalte-gruppentabelle))
   2. Vorgegebene Schlüsselzahlen einstellen (siehe [4. Manuelle Eingabe: Vereinstabelle](04_manuelle_eingabe.md#linke-spalte-vereinstabelle))
   3. Ggf. Spielwochenzuordnung ändern (siehe [4. Manuelle Eingabe: Mannschaftstabelle](04_manuelle_eingabe.md#rechte-spalte-mannschaftstabelle) oder [5.1 Vereinsansicht](05_startbildschirm.md#51-vereinsansicht))
   4. Ggf. Heim-/Auswärtsspielvorgaben setzen (siehe [5.3 Zusätzliche Einstellungen für einzelne Teams](05_startbildschirm.md#53-zusätzliche-einstellungen-für-einzelne-teams))
3. **Schlüsselzahlen generieren** (siehe [6. Schlüsselzahlen generieren](06_generierung.md)).
4. **Konflikte beheben**, falls nötig (siehe [6.1 Konflikte beheben](06_generierung.md#61-konflikte-beheben)).
5. **Ergebnisse kontrollieren**: In der Gruppenansicht der Übersicht (siehe [5.2 Gruppenansicht](05_startbildschirm.md#52-gruppenansicht)).
6. **Ergebnisse speichern und exportieren** (siehe [6.4 Kontrolle und Übergabe](06_generierung.md#64-kontrolle-und-übergabe)).

Wenn Sie Ihre Planung unterbrechen und zu einem späteren Zeitpunkt fortsetzen möchten, können Sie jederzeit über den Button **Speichern** (oder **Strg+S**) in der Übersicht einen Zwischenstand als `Data.json` herunterladen und die gespeicherte Datei zu einem späteren Zeitpunkt über die Datenimport-Seite wieder laden (siehe [3.3 Laden aus Datei](03_datenimport.md#33-laden-aus-datei)).
